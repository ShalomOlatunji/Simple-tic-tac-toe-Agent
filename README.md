# Company Sales Data Visualization

A Python data visualization project that analyzes monthly company sales data using Pandas and Matplotlib.

## Features

- Reads sales data from a CSV file
- Displays total profit for each month using a line chart
- Visualizes bathing soap and facewash sales using subplots
- Saves the generated charts as PNG images
